Evolução da Internet e da Web

A Internet é a rede mundial que interliga computadores e outras redes, enquanto a Web (WWW) é o sistema de páginas e informações acessadas por navegadores sobre essa rede. Atualmente o protocolo IPv6 suporta até 2128 endereços e os sinais ópticos chegam a frações de Vluz.

Linha do Tempo

  1. Surgimento das redes de computadores: nos anos 1960, estudos sobre comutação de pacotes permitiram dividir mensagens em blocos para trafegar entre computadores.
  2. ARPANET: criada em 1969 nos Estados Unidos, foi a primeira rede operacional com comutação de pacotes, servindo de base para a Internet.
  3. TCP/IP: o conjunto de protocolos TCP/IP padronizou a comunicação entre redes diferentes e foi adotado oficialmente na ARPANET em 1983.
  4. DNS: criado em 1983, o sistema de nomes de domínio traduz endereços IP numéricos em endereços legíveis, como sites em .com.br.
  5. Criação da World Wide Web: proposta no fim da década de 1980 para organizar e conectar documentos por meio de links de hipertexto.
  6. Tim Berners-Lee: pesquisador do CERN que idealizou e desenvolveu os primeiros padrões da World Wide Web.
  7. HTML: linguagem de marcação usada para estruturar textos, títulos, listas, tabelas e links nas páginas web.
  8. HTTP: protocolo de transferência de hipertexto que define como navegadores e servidores trocam mensagens.
  9. Navegador: programa que envia requisições ao servidor e interpreta o código para exibir a página ao usuário.
  10. Servidor web: computador e software que armazenam os arquivos dos sites e respondem às solicitações dos navegadores.
  11. Web 1.0 vs. aplicações Web modernas: a Web 1.0 era focada em páginas estáticas e leitura simples; já as aplicações Web modernas são dinâmicas, interativas e funcionam como sistemas completos no navegador.

"A Web não apenas conecta máquinas, ela conecta pessoas." — Referência ao trabalho de Tim Berners-Lee no CERN.

Definições

HTML
Linguagem de marcação que estrutura o conteúdo das páginas na Web.
HTTP
Protocolo que permite a troca de páginas e dados entre o navegador e o servidor.
Navegador
Software usado para acessar endereços web e renderizar páginas na tela.
Servidor web
Ambiente que hospeda páginas e recursos e os envia quando solicitados.
Web 1.0 e Aplicações Web Modernas
Evolução de sites estáticos de apenas leitura para aplicações interativas e ricas em recursos.
