Protocolo HTTP:

O HTTP é o protocolo que permite a troca de informações entre o navegador e o servidor na Web. Quando você acessa um site, o navegador faz um pedido e o servidor envia a página de volta.

Cliente, Servidor, Requisição e Resposta

  • Cliente: o navegador (como Chrome ou Firefox) que pede o conteúdo.
  • Servidor: o computador que guarda o site e responde aos pedidos.
  • Requisição: a mensagem enviada pelo cliente pedindo algo ao servidor.
  • Resposta: a mensagem que o servidor devolve ao cliente com o resultado e o conteúdo.

Métodos GET e POST:

  • GET: pede dados ao servidor (como abrir uma página ou buscar algo). Parâmetros podem aparecer na URL.
  • POST: envia dados ao servidor (como cadastrar um usuário ou enviar um formulário).

Exemplo de Requisição HTTP:

GET /http.html HTTP/1.1
Host: www.exemplo.com.br

Exemplo de Resposta HTTP:

HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8

<h1>Olá, mundo!</h1>

Códigos de Status HTTP:

Código Significado
200 Tudo certo: a requisição funcionou e o conteúdo foi enviado.
301 Movido permanentemente: o endereço mudou e há redirecionamento.
400 Requisição inválida: o servidor não entendeu o pedido.
403 Proibido: você não tem permissão para acessar isso.
404 Não encontrado: a página ou arquivo não existe no servidor.
500 Erro interno do servidor: algo falhou no servidor ao processar o pedido.
